Este projeto consiste em uma aplicação de cadastro e gerenciamento de usuários, desenvolvida em Java utilizando o framework Spring Boot.

A aplicação implementa as principais operações de um CRUD (Create, Read, Update e Delete), permitindo realizar o gerenciamento de usuários de maneira simples e organizada.

O projeto tem como objetivo praticar conceitos de desenvolvimento backend, persistência de dados, integração com banco de dados e construção de aplicações utilizando o ecossistema Spring.

* Funcionalidades
* Cadastrar novos usuários.
* Buscar usuários cadastrados.
* Buscar usuários pelo e-mail.
* Atualizar informações de usuários.
* Excluir usuários.
* Tecnologias utilizadas

Tecnologia	Descrição
Java 25	Linguagem de programação
Spring Boot 4.1.0	Framework backend
Spring Data JPA	Persistência e acesso aos dados
Spring Web MVC	Desenvolvimento web
H2 Database	Banco de dados relacional
Lombok	Redução de código boilerplate
Maven	Gerenciamento de dependências e build
